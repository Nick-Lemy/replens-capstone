# Set-progression follow-up

Notebook 09 reproduces these comparisons from the included numerical feature tables. All hyperparameters use inner participant validation; outer test participants remain excluded. Results are exploratory because these people were inspected in earlier experiments.

- Timing: 97 completed-rep examples, nine videos, six people.
- Geometry: 58 quality-passing examples, six videos, five people.
- Signal context: the earlier 33-example/four-person cohort.
- Capacity models predict a training capacity target from observed-prefix inputs and subtract completed count; test capacity is never an input.

Timing SVR reaches 4.178 MAE on the 97-example cohort. Historical R3D scores 4.837 and the median baseline 4.941 on those same examples. This comparison does not establish the shaking-versus-speed target. Error near failure and per-set curves remain poor; no replacement model was deployed.

Classification is a separate 0–2 RIR task. Its metrics must not be interpreted as exact-RIR accuracy. Cohorts with different quality filters must not be ranked together.

Completed-set review is a distinct application feature. Its observed RIR is calculated from user-confirmed failure and reviewed rep boundaries, not generated by a trained model.
